# TECHWEAR // OS

> **Live Demo:** [https://lelyaler.github.io/techwear-store/](https://lelyaler.github.io/techwear-store/)

Интерактивный веб-магазин модульной одежды и кибер-экипировки в эстетике темного милитари-киберпанка.

## Основные возможности

- **Modular Belt System (MBS) Builder**: интерактивный конфигуратор снаряжения с анатомическим манекеном, слотами экипировки и сохранением конфигурации в параметрах URL.
- **Cyber-Fit Scanner**: калькулятор биометрического подбора размеров одежды, обуви и перчаток под параметры пользователя.
- **Web Audio API Engine**: процедурный аудио-синтезатор звуковых сигналов интерфейса и фонового эмбиента без внешних аудиофайлов.
- **Military Checkout Terminal**: терминал оформления заказа с симуляцией логистического радара на HTML5 Canvas и расчетом доставки.
- **Neural ID Profile**: профиль пользователя с выбором тактической фракции, консольной мини-игрой по дешифровке промокодов и начислением бонусов.
- **N.E.O.N. Cortex**: интерактивный диалоговый модуль поддержки и ответов на частые вопросы (FAQ).
- **Multi-Theme Engine**: быстрое переключение между 4 цветовыми темами оформления.
- **PWA**: поддержка работы в офлайн-режиме через Service Worker и возможность установки на экран устройства.

## Стек

- JavaScript (ES Modules)
- CSS (Custom Properties, BEM, 3D Transforms)
- Canvas API
- Web Audio API
- Vite 8
- Service Worker (PWA)
