## 🛡️ Основные тактические модули (Фичи)

### 🔊 1. Web Audio API Синтезатор (Audio Engine)
* **Низкочастотный эмбиент-гул**: Бесконечный фоновый гул на 3-х осцилляторах (низкий синус, пилообразный суб-бас) с фильтром низкой частоты (Lowpass) и модуляцией LFO для создания атмосферы тёмной лаборатории.
* **Процедурные эффекты**: Звуки клика кнопок, успешной операции, ошибки системы и открытия модальных окон синтезируются на лету — никаких аудиофайлов не скачивается!
* **Умный запуск**: Запуск фонового звука привязан к первому реальному клику пользователя по кнопке/ссылке, что обходит ограничения браузеров на автовоспроизведение.

### 🖼️ 2. Кинематографичный слайд-шоу баннер
* **Автоматическое перелистывание**: Бесконечный цикл смены четырех кибер-образов каждые 6 секунд.
* **CSS Parallax-эффект**: Уходящий слайд плавно сжимается и смещается влево, а входящий — выезжает справа налево с увеличением.
* **Светотень для текста**: Усиленный градиент затемнения на левой стороне (`opacity: 88%` -> `0%`) гарантирует идеальную читаемость белого текста манифеста на любом фоне.
* **Performance-оптимизация**: Отложенная (lazy) подгрузка фонов происходит через 1.5 секунды после события `window.onload`, сохраняя драгоценный мобильный трафик при первой отрисовке.

### 🎒 3. MBS Builder (Modular Belt System)
* **Интерактивный манекен**: Конструктор разгрузочного ремня с возможностью вешать модули (визор, плащ-невидимку, экзоноги) на анатомический манекен.
* **Выносные технологические линии**: Интерактивные круги-слоты и линии-подсказки, показывающие характеристики надетого снаряжения.

### 📟 4. Checkout Terminal & Fit Scanner
* **Консольный терминал**: Полноценный эмулятор командной строки для оформления заказа с поддержкой команд `help`, `promo`, `pay`, `clear`, `exit`, логами шифрования транзакций и анимацией взлома платежного шлюза.
* **Fit Scanner**: Интерактивный калькулятор размера по росту, весу и объему груди с эффектом радарной сетки сканирования.

### 👤 5. Neural ID Profile & Hacking Console
* **Профиль оперативника**: Личный кабинет с ASCII-аватаром тактического черепа, шкалой опыта (XP) и выбором класса специализации (Netrunner, Cyborg, Recon, Operative).
* **Скан-луч**: Анимированная лазерная линия, непрерывно сканирующая аватар сверху вниз.
* **Hacking Mini-game**: Текстовая игра по взлому портов корпорации на подбор правильного хэша для заработка кредитов (Cyber Credits).

## 🛠️ Технологический стек

* **Core**: Vanilla Javascript (компонентная архитектура, ES-модули)
* **Сборщик**: Vite 8.1
* **Стилизация**: CSS Custom Properties (CSS-переменные), BEM-архитектура классов, Hardware-accelerated 3D-анимации
* **Звук**: Web Audio API (OscillatorNode, BiquadFilterNode, GainNode)
* **PWA**: Service Worker (`sw.js`) с кэшированием App Shell, манифест `manifest.json`, поддержка оффлайн-режима и установки на рабочий стол мобильных устройств
* **Сжатие графики**: Pillow (Progressive JPEGs, снижение веса медиа на 90% для мобильного Lighthouse Performance)

## 🚀 Быстрый старт

### 1. Установка зависимостей
Склонируйте репозиторий и установите пакеты:
```bash
git clone https://github.com/Lelyaler/techwear.git
cd techwear
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Откройте в браузере локальный адрес: `http://localhost:5173/`

### 3. Сборка для продакшна
Скомпилировать оптимизированные JS/CSS файлы в папку `dist`:
```bash
npm run build
```

### 4. Деплой на GitHub Pages
Отправка последней сборки на хостинг GitHub Pages:
```bash
npm run deploy
```
