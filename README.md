# TECHWEAR // OS — Modular Cybernetic Apparel Platform

> **Live Demo:** [https://lelyaler.github.io/techwear-store/](https://lelyaler.github.io/techwear-store/)

Интерактивная e-commerce платформа и витрина экипировки в эстетике темного утилитарного киберпанка.

Проект разработан на **React 19 + TypeScript** с использованием **Vite**, строгой статической типизации, модульной компонентной архитектуры и интеграции нативных браузерных API (Web Audio API, HTML5 Canvas API, Service Worker / PWA).

---

## Архитектура и ключевой функционал

### 1. Процедурный звук (Web Audio API)
- Интерактивный звуковой движок без внешних аудиофайлов в сетевом трафике (`OscillatorNode`, `GainNode`).
- Тактильные синтезированные звуки переключения категорий, кликов, ошибок и подтверждения заказов.
- Процедурный фоновый drone-эмбиент низких частот (55/110 Гц) с мягким fade-in/fade-out переходом.

### 2. Биометрический сканер размеров (Cyber-Fit Assistant)
- Алгоритмический подбор точных размеров одежды, обуви и перчаток на основе роста, веса, длины стопы и ладони.
- Сохранение вычисленного биометрического профиля в локальном хранилище и автоматическое применение рекомендованного размера в каталоге.

### 3. Терминал оформления заказа с радаром (HTML5 Canvas)
- Интерактивный CRT-терминал с пошаговой валидацией сектора доставки и канала связи.
- Рендеринг маршрута и телеметрии автономного UAV-дрона на HTML5 Canvas (60 FPS) с анимацией круговой развертки радара и контролем дистанции.
- Поддержка скидочных промокодов и оплата бонусными кредитами.

### 4. Neural ID и консоль дешифровки
- Личный кабинет с выбором тактической фракции (Ghost, Recon, Netrunner, Operative).
- Встроенная интерактивная консоль для ввода команд дешифровки и получения бонусных кредитов.

### 5. PWA и оффлайн-кэширование
- Service Worker (`sw.js`) с кэшированием статических ресурсов, WebP-изображений и манифеста.
- Поддержка установки как самостоятельного десктопного и мобильного приложения.

## Стек технологий

- **Ядро:** React 19, TypeScript
- **Сборщик:** Vite 8
- **Графика и звук:** HTML5 Canvas API, Web Audio API
- **Стилизация:** Чистый CSS (BEM, CSS Custom Properties, Flexbox, CSS Grid)
- **Оффлайн и PWA:** Service Worker, Web App Manifest
- **Деплой:** GitHub Pages
